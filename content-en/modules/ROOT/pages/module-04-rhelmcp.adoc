= Install and Validate RHEL MCP

In this module, you will deploy a personal RHEL MCP Server in your Showroom
namespace. The server connects to your assigned RHEL 10 Edge host over SSH and
can read only these application logs:

* `/var/log/kernel-cve-radar/access.log`
* `/var/log/kernel-cve-radar/error.log`
* `/var/log/kernel-cve-radar/auth-events.jsonl`

Your assigned Edge host is `{edge_host}`. The SSH user is `lab-user`, and the
initial SSH password is `{edge_password}`.

== Use the Showroom Terminal

Run every command in this module from the terminal displayed on the right side
of the lab guide.

The terminal runs in the Showroom Pod with a ServiceAccount that can manage
resources only in your personal namespace:

[source,console,role=execute,subs=attributes+]
----
oc whoami
oc projects
----

Set the namespace used by all commands:

[source,console,role=execute,subs=attributes+]
----
export MCP_NAMESPACE="showroom-pgvrq-{user}"
export EDGE_HOST="{edge_host}"
----

[source,console,role=execute]
----
printf 'MCP_NAMESPACE=%s\nEDGE_HOST=%s\n' \
  "${MCP_NAMESPACE}" "${EDGE_HOST}"
----

[WARNING]
====
Do not continue if `EDGE_HOST` displays `edge.example.com`. That is only the
local documentation build fallback. The workshop administrator must run
`cluster-init/lab-init.sh` so Showroom receives your assigned `edge_host` and
`edge_password`.
====

[IMPORTANT]
====
Do not run `oc new-project`. Your ServiceAccount cannot create projects.

Do not rely on `oc project` in the Showroom terminal. Its kubeconfig may try to
write under `/data`, which is not writable. Every command below specifies
the namespace explicitly with the `MCP_NAMESPACE` shell variable.
====

== Verify the Edge Application Logs

Connect to your assigned RHEL 10 host. The password is `{edge_password}`:

[source,console,role=execute]
----
ssh \
  -o UserKnownHostsFile=/tmp/rhel-mcp-known-hosts \
  -o StrictHostKeyChecking=accept-new \
  lab-user@"${EDGE_HOST}"
----

Verify the operating system and application logs:

[source,console,role=execute]
----
cat /etc/redhat-release

ls -l /var/log/kernel-cve-radar/

for log in \
  /var/log/kernel-cve-radar/access.log \
  /var/log/kernel-cve-radar/error.log \
  /var/log/kernel-cve-radar/auth-events.jsonl
do
  test -r "${log}" && echo "READABLE ${log}"
done
----

The expected files are `access.log`, `error.log`, and
`auth-events.jsonl`.

== Generate the MCP SSH Key on the Edge Host

The Linux MCP Server requires key-based SSH authentication. While still
connected to the Edge host, generate a dedicated key without a passphrase:

[source,console,role=execute]
----
mkdir -p /home/lab-user/.ssh
chmod 700 /home/lab-user/.ssh

if [ ! -f /home/lab-user/.ssh/id_ed25519.rhel_mcp_lab_user ]; then
  ssh-keygen -q -t ed25519 -N '' \
    -f /home/lab-user/.ssh/id_ed25519.rhel_mcp_lab_user \
    -C "rhel-mcp-lab-user@$(hostname -f)"
fi
----

Authorize the public key without adding duplicate entries:

[source,console,role=execute]
----
touch /home/lab-user/.ssh/authorized_keys
chmod 600 /home/lab-user/.ssh/authorized_keys

PUBLIC_KEY="$(
  cat /home/lab-user/.ssh/id_ed25519.rhel_mcp_lab_user.pub
)"

grep -qxF "${PUBLIC_KEY}" /home/lab-user/.ssh/authorized_keys ||
  printf '%s\n' "${PUBLIC_KEY}" \
    >> /home/lab-user/.ssh/authorized_keys
----

Return to the Showroom terminal:

[source,console,role=execute]
----
exit
----

== Copy the Private Key to the Showroom Terminal

Copy the private key from the Edge host. Enter `{edge_password}` when prompted:

[source,console,role=execute]
----
mkdir -p /home/lab-user/.ssh
chmod 700 /home/lab-user/.ssh

scp \
  -o UserKnownHostsFile=/tmp/rhel-mcp-known-hosts \
  -o StrictHostKeyChecking=accept-new \
  lab-user@"${EDGE_HOST}":/home/lab-user/.ssh/id_ed25519.rhel_mcp_lab_user \
  /home/lab-user/.ssh/id_ed25519.rhel_mcp_lab_user

chmod 600 /home/lab-user/.ssh/id_ed25519.rhel_mcp_lab_user
----

[NOTE]
====
The Showroom terminal has `/home/lab-user` mounted from persistent storage, but
its `$HOME` may point to `/data`. Use the explicit `/home/lab-user` paths and
the temporary known-hosts file shown above.
====

Verify passwordless SSH and log access:

[source,console,role=execute]
----
ssh \
  -i /home/lab-user/.ssh/id_ed25519.rhel_mcp_lab_user \
  -o UserKnownHostsFile=/tmp/rhel-mcp-known-hosts \
  -o StrictHostKeyChecking=yes \
  lab-user@"${EDGE_HOST}" \
  'whoami; hostname; tail -n 2 /var/log/kernel-cve-radar/error.log'
----

== Create the SSH Key Secret

[source,console,role=execute]
----
oc create secret generic rhel-mcp-ssh-key \
  -n "${MCP_NAMESPACE}" \
  --from-file=id_ed25519.rhel_mcp.key=/home/lab-user/.ssh/id_ed25519.rhel_mcp_lab_user \
  --dry-run=client -o yaml |
  oc apply -f -
----

== Create the MCP Policy

The policy allows only `read_log_file` calls to your assigned Edge host.

[source,console,role=execute]
----
oc apply -f - <<EOF
apiVersion: v1
kind: ConfigMap
metadata:
  name: rhel-mcp-policy
  namespace: ${MCP_NAMESPACE}
data:
  mcp-policy.yaml: |
    rules:
      - host: "${EDGE_HOST}"
        tools: ["read_log_file"]
        all_users: true
        action: ssh_key
        ssh_key:
          path: /work/id_ed25519.rhel_mcp.key
          user: lab-user
EOF
----

== Deploy the RHEL MCP Server

`LINUX_MCP_ALLOWED_LOG_PATHS` is an explicit, comma-separated file allowlist.
It does not represent a recursively allowed directory.

[source,console,role=execute]
----
oc apply -f - <<EOF
apiVersion: apps/v1
kind: Deployment
metadata:
  name: rhel-mcp
  namespace: ${MCP_NAMESPACE}
spec:
  replicas: 1
  selector:
    matchLabels:
      app: rhel-mcp
  template:
    metadata:
      labels:
        app: rhel-mcp
    spec:
      initContainers:
        - name: prepare-ssh-key
          image: registry.access.redhat.com/ubi9/ubi-minimal:latest
          command: ["/bin/sh", "-c"]
          args:
            - >-
              cp /secret/id_ed25519.rhel_mcp.key
              /work/id_ed25519.rhel_mcp.key &&
              chmod 600 /work/id_ed25519.rhel_mcp.key
          volumeMounts:
            - name: ssh-key-secret
              mountPath: /secret
              readOnly: true
            - name: workdir
              mountPath: /work
      containers:
        - name: rhel-mcp
          image: quay.io/redhat-services-prod/rhel-lightspeed-tenant/linux-mcp-server:latest
          imagePullPolicy: Always
          env:
            - name: LINUX_MCP_USER
              value: lab-user
            - name: LINUX_MCP_VERIFY_HOST_KEYS
              value: "False"
            - name: LINUX_MCP_ALLOWED_LOG_PATHS
              value: /var/log/kernel-cve-radar/access.log,/var/log/kernel-cve-radar/error.log,/var/log/kernel-cve-radar/auth-events.jsonl
          command: ["linux-mcp-server"]
          args:
            - --transport
            - streamable_http
            - --host
            - 0.0.0.0
            - --port
            - "8000"
            - --ssh-key-path
            - /work/id_ed25519.rhel_mcp.key
            - --user
            - lab-user
            - --policy-path
            - /config/mcp-policy.yaml
          ports:
            - name: http
              containerPort: 8000
          readinessProbe:
            tcpSocket:
              port: http
            initialDelaySeconds: 5
            periodSeconds: 10
          volumeMounts:
            - name: workdir
              mountPath: /work
            - name: policy
              mountPath: /config
              readOnly: true
      volumes:
        - name: ssh-key-secret
          secret:
            secretName: rhel-mcp-ssh-key
        - name: policy
          configMap:
            name: rhel-mcp-policy
        - name: workdir
          emptyDir: {}
---
apiVersion: v1
kind: Service
metadata:
  name: rhel-mcp
  namespace: ${MCP_NAMESPACE}
spec:
  selector:
    app: rhel-mcp
  ports:
    - name: http
      port: 8000
      targetPort: http
EOF
----

Wait for the server:

[source,console,role=execute]
----
oc rollout status deployment/rhel-mcp \
  -n "${MCP_NAMESPACE}" \
  --timeout=5m

oc get pods,service \
  -n "${MCP_NAMESPACE}"

oc logs \
  -n "${MCP_NAMESPACE}" \
  deployment/rhel-mcp \
  --tail=50
----

== Verify the Service Endpoint

[source,console,role=execute]
----
curl -i \
  "http://rhel-mcp.${MCP_NAMESPACE}.svc.cluster.local:8000/mcp"
----

A plain HTTP GET normally returns `406 Not Acceptable` with a message requiring
`text/event-stream`. This confirms that DNS and the Service are reachable; curl
is not performing an MCP protocol handshake.

== Test the MCP Tool

Use the MCP Server's Python environment to call `read_log_file` through the MCP
protocol:

[source,console,role=execute]
----
oc exec -i \
  -n "${MCP_NAMESPACE}" \
  deployment/rhel-mcp -- \
  env EDGE_HOST="${EDGE_HOST}" \
  /opt/venvs/mcp/bin/python - <<'PY'
import asyncio
import os
from fastmcp import Client

HOST = os.environ["EDGE_HOST"]
LOGS = [
    "/var/log/kernel-cve-radar/access.log",
    "/var/log/kernel-cve-radar/error.log",
    "/var/log/kernel-cve-radar/auth-events.jsonl",
]

async def main():
    async with Client("http://127.0.0.1:8000/mcp") as client:
        for log_path in LOGS:
            result = await client.call_tool(
                "read_log_file",
                {
                    "host": HOST,
                    "log_path": log_path,
                    "lines": 3,
                },
            )
            print(f"=== {log_path} ===")
            print(result.content[0].text)

asyncio.run(main())
PY
----

All three calls must return log entries.

image::rhel-mcp-tool-log-results.png[RHEL MCP read_log_file results for the allowed application logs,width=90%]

import asyncio

async def main():

asyncio.run(main())

== Troubleshooting

=== SSH Cannot Write under `/data`

Use explicit paths and a writable known-hosts file:

[source,console,role=execute]
----
-o UserKnownHostsFile=/tmp/rhel-mcp-known-hosts
----

=== `oc project` Reports `mkdir /data: permission denied`

Keep `MCP_NAMESPACE` set and pass it with `-n` on every `oc` command. No
project switch is required.

=== MCP Reports `SSH connection closed`

Restart the deployment to clear stale MCP or SSH sessions:

[source,console,role=execute]
----
oc rollout restart deployment/rhel-mcp \
  -n "${MCP_NAMESPACE}"

oc rollout status deployment/rhel-mcp \
  -n "${MCP_NAMESPACE}" \
  --timeout=5m
----

=== View Server Logs

[source,console,role=execute]
----
oc logs \
  -n "${MCP_NAMESPACE}" \
  deployment/rhel-mcp \
  --tail=100
----
