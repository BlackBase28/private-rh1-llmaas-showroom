= 從基礎設施複雜度到模型即服務（Models-as-a-Service）

當基礎設施採自助服務模式卻缺乏明確的管控機制時，問題往往接踵而至：

- 各團隊難以正確申請及規劃 GPU 資源規格
- 多個團隊可能重複部署相同的模型，造成資源浪費
- 昂貴的 GPU 長期閒置或負載過重
- 基礎設施成本持續攀升，卻缺乏明確的責任歸屬
- 開發者需要的是模型存取能力，而非繁瑣的 GPU 管理工作

== 模型即服務：AI 大規模部署的更佳抽象層

為了解決上述挑戰，作為平台工程師，您將設計一個集中式、可重複使用且安全的模型服務層：

**集中式模型管理**

* 平台團隊負責部署與維護模型，並實施完整的生命週期管理
* 版本控制、回滾與測試流程均標準化

**安全 API 閘道**

* 所有模型存取均透過具身份驗證、流量限制的端點進行
* 對所有模型互動提供完整的可觀測性與監控

**對開發者友善的存取方式**

* 開發者無需管理底層硬體即可使用模型
* 各團隊專注於開發 AI 驅動的應用程式、代理及功能

**高效的資源利用**

* GPU 資源在組織內集中共用
* 消除資源浪費，同時確保公平存取與成本控制
